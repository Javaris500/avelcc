# Finding: <short-slug>

Copy this file. Do not edit it in place.

## Class

<blocker | defect | contradiction>

blocker         the dispatch forbids something the work requires
defect          the code or the contract is wrong
contradiction   two authoritative sources disagree

## Filed by

Agent slug and the dispatch this arose under.

## What was needed

The specific thing, in one or two sentences. A path, a permission, a
value, a decision.

## Why it is blocked

What forbids it, quoted, with the path it came from. Not a summary of
the rule, the rule.

## Evidence

What was observed, verbatim. Command and output, or file and line. If
a tool errored, say the tool errored; an error is not a result.

## Workaround applied

What was done instead, and where it lives. Write this even when the
workaround is "nothing, the work stopped here", because a stopped
dispatch and an absorbed one look identical from outside.

## Cost of the workaround

What is now worse than it would have been. If the answer is nothing,
say nothing, and expect to be asked again.

## Resolution requested

What the operator has to decide or provide. One question, answerable
yes or no where possible.

## Do not

Route around the boundary. Absorb this silently. Edit the source of
the restriction to unblock yourself.
